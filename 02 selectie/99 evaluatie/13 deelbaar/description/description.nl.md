## Opgave
Schrijf een programma dat aan de gebruiker twee gehele getallen vraagt en nadien controleert of het tweede een deler is van het eerste. Het tweede getal is niet nul.

#### Voorbeelden

Bij invoer `144` en `6` verschijnt:
```
144 is deelbaar door 6
```

Bij invoer `144` en `25` verschijnt:
```
144 is niet deelbaar door 25
```
