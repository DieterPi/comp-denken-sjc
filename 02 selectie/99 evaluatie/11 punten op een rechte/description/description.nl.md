## Opgave
Er werden drie punten, A, B en C gekozen in het vlak.

Vraag nu aan de gebruiker naar de afstanden |AB|, |AC| en |BC|. Controleer nu met behulp van een bereking of deze punten collineair zijn.

#### Voorbeelden

Als |AB| = `15`, |AC| = `19` en |BC| = `4` dan verschijnt er: 
```
A, B en C liggen op eenzelfde rechte.
```


Als |AB| = `15`, |AC| = `19` en |BC| = `10` dan verschijnt er: 
```
A, B en C liggen niet op eenzelfde rechte.
```
