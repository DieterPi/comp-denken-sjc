## Opgave
Vraag een geheel getal x dat uit drie cijfers bestaat aan de gebruiker. Zoek vervolgens het kleinste getal groter dan x dat uit dezelfde cijfers bestaat.

Als er geen zo'n getal bestaat, geef dit dan ook weer.

#### Voorbeelden

Bij invoer `156` verschijnt er:
```
165 is groter dan 156
```

Bij invoer `351` verschijnt er:
```
513
```

Bij invoer `330` verschijnt er:
```
Er is geen oplossing voor dit getal.
```
